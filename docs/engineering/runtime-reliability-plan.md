# 런타임 실패 안정화 실행계획

관련 요구사항: [ISS-001·ISS-002·ISS-006](../requirements/timeline.md) ·
[GRPH-001](../requirements/knowledge-graph.md) ·
[공통 예외 EX-03·EX-04](../REQUIREMENTS.md#6-공통-내부-예외)

상위 일정: [개발 로드맵](roadmap.md#후속-안정화)

이 문서는 실제 실행에서 확인된 실패를 다시 일으키지 않기 위한 작업 순서와 완료 조건을
관리한다. 아직 구현하지 않은 동작은 이 문서에만 계획으로 기록한다. 구현할 때 요구사항,
AI 명세, HTTP 계약과 검증 문서를 같은 변경에서 갱신한다.

RH-01~RH-07은 코드·단위 회귀·계약 문서에 반영됐다. RH-08~RH-09와 전체 종료 게이트는 아직
남아 있으므로 이 실행계획 전체를 완료로 판정하지 않는다.

## 1. 확인된 현상과 판정

- `gemini-3.6-flash` 호출이 `503 UNAVAILABLE`과 `429 Too Many Requests`로 중단됐다. 현재 기본
  모델은 `gemini-3.5-flash-lite`로 바뀌었지만, 오류 코드와 무관하게 한 번만 재시도하는 구조는
  그대로다.
- 날짜가 없는 `영남권 산불` 입력을 모델이 `2024년 3월`로 좁혔다. 검색기는 그 기간을 강제해
  2025년 기사를 제외하고 첫 라운드에서 `no_articles`로 종료했다.
- 같은 입력을 2025년으로 해석한 실행은 검색 후보를 확보했지만 P4가 기사 0건을 선택했다.
  첫 라운드의 이전·현재 선정 건수가 모두 0이어서 즉시 `converged`로 종료했다.
- `2025년 주요 정치 이슈` 타임라인은 기사 17건으로 저장됐지만, 이어진 지식 그래프 추출에서
  관계의 `source` 또는 `target`이 `entities`에 없어 구조 검증에 실패했다.
- 로그에는 P3의 실제 검색어·적용 기간, 검색 결과와 MS-SQL 복원 건수, P4 탈락 사유, 그래프의
  실패 기사와 관계 끝점이 남지 않는다. 따라서 일부 실패는 종료 단계만 확인되고 정확한 입력은
  재구성할 수 없다.

## 4. 필수 회귀 사례

- 날짜가 없는 `영남권 산불`이 2025년 기사 후보를 반환한다.
- 모델이 잘못된 기간을 만들면 기간 없는 두 번째 검색으로 복구한다.
- 두 검색 모두 결과가 없을 때만 `no_articles`를 반환한다.
- 후보가 있는데 첫 P4 응답이 비어도 즉시 수렴하지 않는다.
- 두 번째 라운드부터 새 기사 ID가 없을 때만 `converged`로 종료한다.
- 존재하지 않는 기사 ID와 가상 이벤트는 기존 규칙대로 저장하지 않는다.
- 그래프 관계 끝점이 엔티티 목록에 없으면 수정 생성 또는 관계 제외가 수행된다.
- `404`, `429`, `503`, 구조 검증 실패가 서로 다른 오류와 호출 횟수로 처리된다.
- 실제 MCP `search_articles`로 `영남권 산불`, 2025년 기간, `hybrid`, `top_k=20`을 호출하면
  1건 이상의 MS-SQL 복원 기사가 반환된다.

## 5. 실행 순서와 종료 게이트

```text
RH-01 관측 보강
   ↓
RH-02 기간 정책 → RH-03 무결과 복구 → RH-04 선정·수렴 복구
   ↓
RH-05 그래프 출력 복구
   ↓
RH-06 오류 정책 → RH-07 실제 모델 점검
   ↓
RH-08 회귀 검사 → RH-09 사용자 오류 안내
```

각 작업은 변경 파일을 다시 읽고 문서 라우팅 결과를 대조한 뒤 `make check`를 통과해야 한다.
검색 변경은 실제 MCP 검색, 그래프 변경은 MS-SQL 기사 단위 저장과 SSE, 모델 변경은
`make ai-smoke`, 사용자 흐름 변경은 `make test-e2e`를 추가로 확인한다. 모든 항목과 실데이터
검사가 통과하기 전에는 이 계획을 완료로 표시하지 않는다.
