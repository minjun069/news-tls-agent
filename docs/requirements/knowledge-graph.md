# 지식 그래프 요구사항

관련 공통 PRD: [`../REQUIREMENTS.md`](../REQUIREMENTS.md)

## 요구사항

| ID | 요구사항 | 우선순위 | 상태 |
|---|---|---|---|
| GRPH-001 | 이슈의 인물·기관·장소·사건과 관계를 그래프로 볼 수 있어야 한다 | Could | 기획 |

## Acceptance Criteria

| ID | Given | When | Then |
|---|---|---|---|
| AC-020 | 이슈 이벤트가 2건 이상일 때 | 지식 그래프를 열면 | 엔티티가 노드, 관계가 간선으로 표시된다 |
| AC-021 | 관계 미추출 대표 기사가 있을 때 | 그래프를 열면 | 추출 중을 표시하고 완료 후 그래프를 보여준다 |

## 기능 상세

```text
대표 기사 목록 조회
       ↓
기사별 관계 추출 여부 확인
       ├─ 미추출 → LLM 추출 → 기사 단위 저장 ─┐
       └──────────────────────────────────────┘
       ↓
대표 기사별 엔티티·관계 조회
       ↓
기사별 그래프 구성
```

- 여러 기사를 하나의 통합 그래프로 합치지 않고 기사별 그래프를 만든다.
- 출처 기사가 없는 엔티티·관계는 저장하지 않는다.
- 엔티티 표면형을 그대로 사용하고 다른 호칭을 병합하지 않는다.
- 이벤트가 1건 이하면 그래프를 제공하지 않는다.

기사별 구성을 택한 이유는 정규화 없이 통합하면 같은 인물이 여러 노드로 갈라지기 때문이다. LLM·저장 실패는 공통 EX-03·EX-05를 따른다.
