# 브리핑 내보내기 요구사항

관련 공통 PRD: [`../REQUIREMENTS.md`](../REQUIREMENTS.md)

## 요구사항

| ID | 요구사항 | 우선순위 | 상태 |
|---|---|---|---|
| CHAT-006 | 사용자는 대화로 내보내기 의도를 전달해 실행할 수 있어야 한다 | Should | 기획 |
| EXP-001 | 이슈 브리핑을 PDF로 내려받을 수 있어야 한다 | Should | 기획 |
| EXP-002 | 이슈 브리핑을 Notion 페이지로 저장할 수 있어야 한다 | Should | 기획 |

## Acceptance Criteria

| ID | 관련 | Given | When | Then |
|---|---|---|---|---|
| AC-015 | CHAT-006 | 답변을 받은 뒤 | 대화로 PDF 저장을 요청하면 | 별도 메뉴 없이 파일을 제공한다 |
| AC-016 | CHAT-006 | 형식 없이 저장을 요청했을 때 | 에이전트가 응답하면 | 형식을 되묻는다 |
| AC-017 | EXP-001 | 이슈 상세를 보고 있을 때 | PDF 내보내기를 선택하면 | 브리핑 PDF가 내려받아진다 |
| AC-018 | EXP-002 | Notion 연결이 설정됐을 때 | 저장을 선택하면 | 지정 상위 페이지 아래에 만들고 URL을 표시한다 |
| AC-019 | EXP-002 | Notion 연결이 없을 때 | 저장을 선택하면 | 연결 설정 필요를 안내한다 |

## 기능 상세

- 입력: 이슈 식별자, PDF/Notion 형식, Notion인 경우 상위 페이지 식별자
- 처리: 이슈 조회 → 브리핑 구성 → 형식 변환 → 파일 반환 또는 외부 저장
- 대화 요청은 직전 답변만이 아니라 **이슈 브리핑 전체**를 대상으로 한다.
- 대상이나 형식이 모호하면 실행 전에 되묻는다.
- Notion 연결 정보가 없으면 외부 저장을 시도하지 않는다.
- 내보내기 의도는 정규식이 아니라 에이전트의 도구 선택으로 처리한다([ADR-0004](../decisions/0004-export-intent-via-tool.md)).

저장 실패는 공통 EX-05를 따른다.
