# 근거 기반 대화 요구사항

관련 공통 PRD: [`../REQUIREMENTS.md`](../REQUIREMENTS.md)

## 요구사항

| ID | 요구사항 | 우선순위 | 상태 |
|---|---|---|---|
| CHAT-001 | 이슈를 보면서 에이전트와 대화할 수 있어야 한다 | Must | 기획 |
| CHAT-002 | 에이전트가 검색·조회한 기사를 근거로 답해야 한다 | Must | 기획 |
| CHAT-003 | 기사에 없는 관련 배경 개념도 확인할 수 있어야 한다 | Should | 기획 |
| CHAT-004 | 기사 근거와 일반 지식 부분을 구분할 수 있어야 한다 | Must | 기획 |
| CHAT-005 | 답변 완성 전 생성 중인 내용을 볼 수 있어야 한다 | Should | 기획 |

CHAT-004는 CHAT-003의 전제다. 일반 지식 허용 시 출처를 구분하지 않으면 근거 없는 서술이 기사 근거처럼 보인다.

## Acceptance Criteria

| ID | 관련 | Given | When | Then |
|---|---|---|---|---|
| AC-011 | CHAT-002, CHAT-004 | 기사에서 확인 가능한 사실을 물었을 때 | 답변하면 | 근거 기사가 함께 제시된다 |
| AC-012 | CHAT-003, CHAT-004 | 기사에 없는 개념을 물었을 때 | 답변하면 | 기사에서 확인되지 않은 일반 지식임을 표시한다 |
| AC-013 | CHAT-001 | 데이터 접근 계층이 중단됐을 때 | 질문하면 | 자료를 불러오지 못했음을 안내한다 |
| AC-014 | CHAT-005 | 질문했을 때 | 답변 생성 중이면 | 완성 전 부분 텍스트가 표시된다 |

## 기능 상세

1. 이슈 식별자, 질문, 필요한 대화 이력을 받는다.
2. 에이전트가 필요에 따라 MCP의 기사 검색·조회 도구를 호출한다.
3. 기사 근거와 모델 일반 지식을 구분해 스트리밍 응답한다.
4. 참조 기사 ID와 도구 호출 진행 상태를 함께 전달한다.

컨텍스트 주입 범위와 대화 이력 유지 방식은 구현 결과를 보고 정한다. 데이터 접근 실패와 LLM 실패는 공통 EX-03·EX-06을 따른다.
