# news-tls-agent PRD

## 1. 문서 개요

- 제품명: news-tls-agent (뉴스 타임라인 요약 에이전트)
- 목적: 구현 범위와 사용자가 얻어야 할 결과를 정의한다.
- 범위: 뉴스 타임라인 생성, 근거 확인, 근거 기반 대화, 브리핑 내보내기, 지식 그래프
- 상태: 기획 중
- 주 개발 도구: Codex

기능별 요구사항·Acceptance Criteria(AC)·정책·예외는 [`requirements/`](requirements/)에 나눈다. 이 문서는 공통 문제·목표·범위와 기능 목차의 단일 원천이다.

## 2. 문제 정의

뉴스는 사건이 아니라 기사 단위로 유통된다. 하나의 사건이 수십~수백 건의 기사로 쪼개져 시간에 흩어지고 같은 사실이 반복 보도된다. 사용자는 날짜순 검색 결과를 훑으며 순서를 재구성하고, 중복을 제거하고, 중요한 분기점을 판단하고, 세부 사실을 다시 찾아야 한다.

LLM 요약도 근거를 알 수 없으면 확인 작업이 다시 발생한다. 따라서 제품이 풀 핵심 문제는 다음과 같다.

> **신뢰성이 확보된 상태로 정보를 조직화해, 사용자가 이슈를 파악하는 데 드는 시간을 크게 줄이는 것.**

근거 귀속은 신뢰성을 확보하는 수단이다. 원문 확인 경로는 열어두되, 사용자가 매번 원문을 읽지 않아도 신뢰할 수 있어야 한다.

**검증 가설**: 각 분기점에 근거 기사가 귀속되고 그 근거를 바탕으로 대화할 수 있으면, 사용자는 원문을 직접 읽지 않고도 이슈를 신뢰 가능한 수준으로 파악할 수 있다.

## 3. 목표와 비목표

### 3.1 Product Goals

- 흩어진 기사를 사건 단위 타임라인으로 조직화해 이슈 파악 시간을 줄인다.
- 모든 서술에 근거를 귀속해 원문 확인 없이도 내용을 신뢰할 수 있게 한다.
- 정리 결과를 외부로 내보내 다른 작업에서 재사용할 수 있게 한다.

### 3.2 User Goals

- 관심 이슈의 전개를 시간순 타임라인으로 파악한다.
- 각 분기점의 대표 근거 기사와 원문을 즉시 확인한다.
- 원문을 직접 읽지 않고도 기사 근거 대화로 세부 내용을 습득한다.
- 기사에 없는 관련 배경 개념도 일반 지식임을 구분한 설명으로 확인한다.
- 브리핑을 PDF로 받거나 Notion에 저장해 활용한다.

### 3.3 Project Goals

- MCP 데이터 접근 계층, MS-SQL 정규화 스키마, Qdrant 검색을 실제 서비스로 구현한다.
- AI 에이전트와 실행 관찰 체계를 구축한다.
- 지식 그래프 구축·시각화를 구현한다.
- Codex용 개발 하네스와 CI/CD 검증 체계를 구축한다.
- 설계 결정의 배경과 근거를 문서와 ADR로 남긴다.

상업 서비스가 아니므로 수익·성장 중심 Business Goals 대신 Project Goals를 구분한다.

### 3.4 MVP 범위

| 구분 | 포함 범위 |
|---|---|
| 데이터 | 뉴스 토픽 2~3개분 기사 |
| 생성 | 검색·검증 루프 기반 타임라인 |
| 데이터 접근 | MCP 서버 경유 |
| 저장 | MS-SQL 정규화 스키마 |
| 검색 | BM25·벡터·결합 검색을 준비하고 에이전트가 선택하거나 모두 수행 |
| 대화 | 기사 근거 + 일반 지식, 출처 구분 |
| 내보내기 | PDF, Notion |
| 시각화 | 기사별 엔티티 관계 그래프 |
| 사용자 | 단일 사용자, 인증 없음 |

컨텍스트 주입 범위와 이력 관리 방식, 생성 루프의 세부 상한은 구현 결과를 보고 결정한다.

- 별도 심층 분석·핵심 용어 생성

## 4. 사용자

| 사용자 | 핵심 니즈 |
|---|---|
| 이슈 추적자 | 사건 흐름을 시간순으로 빠르게 파악 |
| 심화 질문자 | 원문을 직접 읽지 않고 근거 답변과 배경 개념 습득 |
| 정리·활용 사용자 | PDF 다운로드와 Notion 저장 |

### 4.1 핵심 시나리오

**타임라인 생성과 근거 확인**

1. 사용자가 새 토픽을 입력한다.
2. 진행 단계와 라운드를 확인한다.
3. 완료된 시간순 이벤트와 요약을 읽는다.
4. 마일스톤을 선택하면 관련도 1위 대표 기사가 바로 표시된다.
5. 필요하면 나머지 근거 기사를 관련도 순으로 보고 원문 URL로 이동한다.

**대화로 세부와 배경 습득**

1. 사용자가 요약에 없는 세부를 질문한다.
2. 에이전트가 기사를 검색·조회하고 근거와 함께 답한다.
3. 사용자가 모르는 관련 개념을 이어서 묻는다.
4. 에이전트가 기사 근거가 아닌 일반 지식임을 표시해 설명한다.

**브리핑 활용**

1. 사용자가 대화로 PDF 저장을 요청하거나 화면 메뉴를 사용한다.
2. 에이전트가 의도와 대상을 확인해 PDF를 제공한다.
3. 또는 지정한 Notion 상위 페이지 아래에 브리핑을 저장하고 URL을 표시한다.

사용자에게 보이는 결과는 기능 문서의 AC가 정의한다. 아래 EX는 사용자 행동과 직접 연결되지 않는 내부 처리 규칙이다.

| ID | 상황 | 기대 동작 |
