# MS-SQL 마이그레이션

스키마 계약은 [`../../docs/ERD.md`](../../docs/ERD.md), 실행 순서는 `migrations/`가 원본이다.
`schema.sql`은 현재 전체 구조를 한 번에 읽기 위한 참고본이며 실행하지 않는다.

## 규칙

1. 번호는 증가만 한다.
2. 한 번 적용된 파일은 수정하지 않는다. 체크섬이 달라지면 실행기가 실패한다.
3. 되돌리거나 고치는 작업도 새 번호의 마이그레이션으로 작성한다.

## 실행

저장소 루트에서 다음 명령을 실행한다.

```bash
make migrate
```

`000_bootstrap.sql`은 대상 DB와 `schema_migrations`를 만들기 위해 `master`에서 자동 커밋으로
실행되는 유일한 예외다. `001`부터는 파일 하나와 적용 이력 기록이 같은 트랜잭션에 들어간다.
이미 적용된 파일은 건너뛰므로 같은 명령을 반복해도 된다.

환경변수는 루트 `.env`에서 읽는다. `MSSQL_HOST`가 비어 있으면 WSL 기본 게이트웨이를
Windows 호스트로 해석한다.
